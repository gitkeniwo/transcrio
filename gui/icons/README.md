# Transcrio app icons

Final icon set exported from the design canvas. Each file is a standalone 1024×1024 SVG.

- The icon body follows the macOS grid: an 824 squircle at (100,100) with rx 185.
- No shadow is baked in.
- Text is live `<text>` in American Typewriter or SF Mono. Rasterize on macOS, or convert it to outlines before shipping.

| File | Design | Role |
|---|---|---|
| `a3b-lcd-clay.svg` | A3b typewriter, LCD bar display, clay (orange) | **Default app icon** |
| `a3b-crt-gold.svg` | A3b typewriter, CRT display, gold | Alternate |
| `a3b-ribbon-ivory.svg` | A3b typewriter, ink-ribbon display, ivory | Alternate |
| `a3b-led-navy.svg` | A3b typewriter, LED segment display, navy | Alternate |
| `a3d-bars.svg` | A3d typewriter, waveform bars on paper | Alternate |
| `h3-olive.svg` | H3 scan terminal, seam high, olive control plate | Alternate |
| `h3b.svg` | H3b scan terminal, seam low | Alternate |
| `h5.svg` | H5 electronic typewriter with LCD | Alternate |
